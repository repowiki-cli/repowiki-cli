# context

> Path: `plugin-context/src/commands/context`

## Overview
The `context` directory in the TypeScript project contains classes that manage different aspects of the plugin context. It includes `ContextIndex` for organizing contextual data, `ContextQuery` for handling context-related queries, and `ContextServe` for managing the "serve" command within the context plugin. These classes work together to provide a structured and functional context management system.
