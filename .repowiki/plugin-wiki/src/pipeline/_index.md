# pipeline

> Path: `plugin-wiki/src/pipeline`

## Overview
This directory contains pipeline-related classes used in the wiki plugin. `GeneratePipeline` orchestrates the generation process, while `ValidatePipeline` ensures data integrity by validating data as it moves through the pipeline. Both classes are essential for processing and maintaining the quality of wiki content.
