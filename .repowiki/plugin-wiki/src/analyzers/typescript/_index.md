# typescript

> Path: `plugin-wiki/src/analyzers/typescript`

## Overview
The directory is part of the `plugin-wiki` project and contains the `TypeScriptAnalyzer` class, which is used to analyze TypeScript code. It includes a `queries` subdirectory that houses the `extractExports` function, responsible for retrieving exported symbols from TypeScript files. This structure supports code analysis and documentation generation within the project.
