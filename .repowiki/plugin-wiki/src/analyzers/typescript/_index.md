# typescript

> Path: `plugin-wiki/src/analyzers/typescript`

## Overview
**Directory:** `plugin-wiki/src/analyzers/typescript`  
This directory contains the core components for analyzing TypeScript code within the `plugin-wiki` project. It includes the `TypeScriptAnalyzer` class, which performs general analysis, and the `queries` module, which focuses on extracting exported symbols from TypeScript files. Together, they enable symbolic and structural analysis of TypeScript code for documentation and reference purposes.
