# progress

> Path: `plugin-wiki/src/progress`

## Overview
The `progress` module in the `plugin-wiki` package provides types and utilities for tracking and reporting progress within an application. It defines the `ProgressEvent` type to represent progress events and the `ProgressReporter` type to describe objects that can report progress. The `createProgressReporter` function is used to instantiate a progress reporter, enabling components to track and update progress state.
