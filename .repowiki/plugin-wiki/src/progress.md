# progress

> Path: `plugin-wiki/src/progress`

## Overview
The `progress` module in the `plugin-wiki` package provides types and utilities for tracking and reporting progress within an application. It defines the `ProgressEvent` type, which represents a progress update, and the `ProgressReporter` type, which outlines the interface for reporting progress. The `createProgressReporter` function is used to instantiate a progress reporter that can emit progress events.
