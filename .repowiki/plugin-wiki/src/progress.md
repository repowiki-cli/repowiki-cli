# progress

> Path: `plugin-wiki/src/progress`

## Overview
The `progress` module in the `plugin-wiki` package provides types and utilities for tracking and reporting progress within an application. It defines the `ProgressEvent` type to represent progress updates and the `ProgressReporter` type to describe objects that can emit such events. The `createProgressReporter` function is used to instantiate a new progress reporter instance.
