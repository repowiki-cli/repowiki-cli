# createProvider

> Path: `plugin-wiki/src/providers/createProvider`

## Overview
The `createProvider` module exports a function used to create a provider instance. It also includes the `providerEnvKey` function, which returns the corresponding environment variable name for a given provider key, or null if no environment variable is needed. This module is utilized to manage provider configurations and their associated environment settings.

## Exports
- `function createProvider`
- `function providerEnvKey` — Returns the env var name for a provider key, or null if not needed.
