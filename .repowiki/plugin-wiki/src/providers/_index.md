# providers

> Path: `plugin-wiki/src/providers`

## Overview
This directory contains the core provider implementations and utilities for integrating with various AI service providers. It includes classes such as `AnthropicProvider`, `AzureOpenAIProvider`, and `OpenAIProvider`, each designed to interface with their respective AI platforms. Additionally, the `createProvider` module offers functions for initializing and managing these providers within the application.
