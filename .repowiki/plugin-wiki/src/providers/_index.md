# providers

> Path: `plugin-wiki/src/providers`

## Overview
This directory contains provider classes and utilities for integrating with various AI service providers. It includes `AnthropicProvider`, `AzureOpenAIProvider`, and `OpenAIProvider`, each handling integration with their respective APIs. The `createProvider` module provides a function to instantiate providers and retrieve environment variable keys.
