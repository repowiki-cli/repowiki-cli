# backends

> Path: `plugin-wiki/src/backends`

## Overview
This directory contains backend utilities for a TypeScript project, specifically for handling local markdown content and managing application manifests. The `LocalMarkdownBackend` class is responsible for accessing and processing locally stored markdown files. The `ManifestManager` class handles the creation, retrieval, and management of application manifests.
