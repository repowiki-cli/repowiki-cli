# @repowiki/plugin-wiki

> Path: `plugin-wiki`

## Overview
The `node` package in the TypeScript project serves as a container for the wiki plugin's core functionality. It includes the `src/plugin-wiki` directory, which houses modules responsible for processing, generating, and managing wiki content. This structure supports the development and integration of wiki-related features within the application.
